# CLAUDE.md — agent Python

> Chargé seulement quand on travaille sous `agent/`. Les règles communes au projet sont dans `../CLAUDE.md`.

## Pièges

- **Ordre d'import dans `main.py`** : `install()` du patch multimodal doit précéder l'import des graphes. Le patch remplace l'attribut de module `ag_ui_langgraph.utils.convert_agui_multimodal_to_langchain` : après une montée de version d'`ag-ui-langgraph`, vérifier qu'un PDF attaché arrive encore au modèle (symptôme d'un patch devenu inopérant : l'agent ne « voit » aucun document).
- **`recursion_limit`** se règle dans `_AGENT_CONFIG` de `main.py` : un `.with_config()` sur le graphe est écrasé par la config qu'`ag_ui_langgraph` construit à chaque run.
- **Dashboard `/fixed`** : les bindings `{path}` de `src/a2ui/schemas/dashboard.json` (`/kpis/0..3/*`, `/trend`, `/share`, `/rows`, `/scope/*`…) doivent correspondre au data model écrit par `render_dashboard` (`src/fixed_agent.py`). Changer l'un sans l'autre donne des slots vides, sans erreur.
- **IDs de modèles et paramètres** (température, timeout, retries) vivent uniquement dans `src/models.py` ; les sites d'appel passent par `chat_model(...)`. IDs datés, jamais `-latest`. Tests : `uv run pytest` (le `conftest.py` pose une fausse `MISTRAL_API_KEY`, les modèles étant instanciés à l'import).
- **Hook httpx de CopilotKit** : `CopilotKitMiddleware` pose un hook de requête sur `model.client` et `model.async_client`. `ChatMistralAI` expose un `httpx.AsyncClient` brut, qui `await` chaque hook : avec `copilotkit` 0.1.90 (hook synchrone) tout appel async échouait en `TypeError: object NoneType can't be used in 'await' expression`. Corrigé en passant à `copilotkit` ≥ 0.1.93 (hook async pour `AsyncClient`) ; ne pas redescendre. Garde-fou : `tests/test_httpx_hook.py` (modèle Mistral réel sur `httpx.MockTransport`, hors réseau).
- **Erreurs Mistral** : `MistralErrorMiddleware` (`src/errors.py`) doit rester **après** `CopilotKitMiddleware` dans `middleware=[…]`. Le premier de la liste est le plus externe : placé après, il enveloppe l'appel au modèle au plus près et capte l'exception avant que le middleware CopilotKit ne la voie. Les erreurs des sous-LLM dans les outils reviennent en `ToolMessage` préfixé `MISTRAL_ERROR: ` ; `before_model` saute alors à la fin (`jump_to: end`) avec le message français, sans quoi le modèle rappellerait l'outil en boucle. Toute autre exception est relancée telle quelle.
